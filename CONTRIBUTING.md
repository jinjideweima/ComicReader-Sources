# Contributing

Changes must remain reviewable and narrowly scoped.

1. Do not add credentials, cookies, tokens, captured private responses, or
   copyrighted content samples.
2. Declare every network host used directly or returned for image loading.
3. Use the least permissive content rating and permissions that remain honest.
4. Do not add code intended to bypass authentication, payment, rate limits,
   regional restrictions, or technical protection measures.
5. Update a plugin version whenever its script bytes change.
6. Run `Tools/sign-index.sh` and `swift Tools/validate_repository.swift` before
   committing an index update.

Contributions are provided under Apache License 2.0 as described by section 5
of that license. Contributors must have the right to submit their changes.
