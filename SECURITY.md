# Security Policy

Do not open a public issue for leaked credentials, a signature-key compromise,
host allowlist escape, malicious script update, or another vulnerability that
could put users at risk. Use GitHub Private Vulnerability Reporting for this
repository.

Include the affected plugin version and commit, reproduction steps, impact,
and the smallest safe test case. Never submit real cookies, tokens, passwords,
private content, or another person's data.

Repository signing private keys must not be committed, attached to issues, or
stored in workflow artifacts. A suspected key compromise requires a new key,
an explicit migration notice, and user re-review.
